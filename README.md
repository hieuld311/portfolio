# hieuld portfolio

A static portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Pages

- Home
- Gallery
- Career

## Content sources

- Update gallery images in `public/gallery/` and `src/data/gallery.ts`.
- Update career offices, timeline records, projects, and highlights in `src/data/career.ts`.

## Commands

```bash
npm run dev
npm run build
npm run lint
```
